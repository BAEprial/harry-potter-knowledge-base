# 记忆瓶


| 项目 | 内容 |
|---|---|
| 名称 | 记忆瓶 |
| 英文名 | Memory Vials |
| 类别 | 魔法道具 |
| 说明 | 储存记忆的小玻璃瓶，通常用于在冥想盆中回顾记忆。记忆以银色丝状物质的形式被抽出，可以储存在瓶中长期保存。邓布利多和斯内普都用记忆瓶保存了关键记忆，如斯内普临终前交给哈利的记忆揭示了整个真相。 |
