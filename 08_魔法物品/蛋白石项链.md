# 蛋白石项链


| 项目 | 内容 |
|---|---|
| 名称 | 蛋白石项链 |
| 英文名 | Opal Necklace |
| 类别 | 黑暗物品 |
| 说明 | 博金-博克店出售的一条被诅咒的蛋白石项链——据说它已经夺去了十九个麻瓜的生命。被诅咒的人触碰它会陷入极度痛苦直至死亡。德拉科·马尔福在六年级将它交给被夺魂咒控制的凯蒂·贝尔，试图以此刺杀邓布利多。凯蒂不慎触碰到项链后被升上空中、痛苦尖叫，在圣芒戈住了数月才康复。 |
