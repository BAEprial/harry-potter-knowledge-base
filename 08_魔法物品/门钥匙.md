# 门钥匙


| 项目 | 内容 |
|---|---|
| 名称 | 门钥匙 |
| 英文名 | Portkey |
| 类别 | 魔法道具 |
| 说明 | 被施了魔法的普通物品，可以将接触它的人瞬间传送到预定地点。通常在预定时间激活（如三强争霸赛杯），但也有可以随时激活的版本。门钥匙是巫师旅行的重要方式之一，特别是对于无法幻影移形的人。在"七个波特"行动中，门钥匙是转移哈利的重要工具。 |
