# 阿尼马格斯形态


| 项目 | 内容 |
|---|---|
| 名称 | 阿尼马格斯形态 |
| 英文名 | Animagus Transformation |
| 类别 | 传奇物品 |
| 说明 | 严格来说不是一个"物品"，而是一种极为高级的魔法能力——能够随意变成特定动物的巫师被称为阿尼马格斯。每个巫师只能变成一种与其性格匹配的动物。已知的阿尼马格斯包括：麦格教授（虎斑猫）、詹姆·波特（雄鹿"尖头叉子"）、小天狼星（大黑狗"大脚板"）、彼得·佩迪鲁（老鼠"虫尾巴"）和丽塔·斯基特（甲虫，未注册）。所有阿尼马格斯必须在魔法部注册，非法变形是严重罪行。 |
