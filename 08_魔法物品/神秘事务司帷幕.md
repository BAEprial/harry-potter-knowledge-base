# 神秘事务司帷幕


| 项目 | 内容 |
|---|---|
| 名称 | 神秘事务司帷幕 |
| 英文名 | The Veil |
| 类别 | 传奇物品 |
| 说明 | 魔法部神秘事务司死亡室中一个石拱门上悬挂的破旧帷幕——它是生与死之间的神秘边界。帷幕会轻轻飘动，仿佛有微风（但死亡室里没有风）。卢娜和哈利可以听到帷幕后面微弱的低语声——那是逝者的声音。小天狼星在决斗中被贝拉特里克斯的咒语击中后坠入帷幕，永远消失。这个古老的神秘装置是魔法世界中对死亡本质研究最深入的文物之一。 |
