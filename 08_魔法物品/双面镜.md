# 双面镜


| 项目 | 内容 |
|---|---|
| 名称 | 双面镜 |
| 英文名 | Two-Way Mirror |
| 类别 | 魔法道具 |
| 说明 | 一对魔法镜子，持有者可以通过镜子实时见到和交谈对方——类似巫师世界的视频通话。小天狼星将其中一面送给哈利，自己保留另一面。哈利在小天狼星死后才打开礼物，追悔莫及——如果他早用镜子就不会被伏地魔用假象引诱到神秘事务司。后来阿不福思·邓布利多获得了小天狼星的那面，在危急时刻通过它派多比前来营救哈利。 |
