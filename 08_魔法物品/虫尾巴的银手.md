# 虫尾巴的银手


| 项目 | 内容 |
|---|---|
| 名称 | 虫尾巴的银手 |
| 英文名 | Wormtail's Silver Hand |
| 类别 | 黑暗物品 |
| 说明 | 伏地魔赐给彼得·佩迪鲁（虫尾巴）的一只银色魔法手——替代他在复活仪式中自愿献出的右手。这只银手力大无穷，但暗藏杀机：当虫尾巴在马尔福庄园地牢中对哈利产生了一丝犹豫和同情时，银手立刻反过来掐住了虫尾巴自己的喉咙并将其勒死。这是伏地魔的保险措施——他对背叛零容忍。邓布利多早已预见到这只手终将杀死虫尾巴。 |
