# 消失柜


| 项目 | 内容 |
|---|---|
| 名称 | 消失柜 |
| 英文名 | Vanishing Cabinet |
| 类别 | 魔法道具 |
| 说明 | 一对神奇的柜子，形成一个传送通道——进入其中一个柜子的人会从另一个柜子出来。霍格沃茨和博金-博克店各有一个。德拉科·马尔福花了一整年修复霍格沃茨的消失柜，最终让食死徒通过它入侵霍格沃茨，导致了邓布利多的死亡。弗雷德和乔治曾把蒙顿格斯塞进消失柜做恶作剧。 |
| 是否已毁 | 霍格沃茨的消失柜在战斗中被毁 |
