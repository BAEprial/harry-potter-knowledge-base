# 窥镜


| 项目 | 内容 |
|---|---|
| 名称 | 窥镜 |
| 英文名 | Sneakoscope |
| 类别 | 魔法道具 |
| 说明 | 一种黑魔法探测器，外形像小型玻璃陀螺。当不可信的人在附近时，它会发光、旋转并发出尖啸声。罗恩在三年级从埃及给哈利买了一个作为生日礼物。它在霍格沃茨特快列车上不断作响——因为虫尾巴（彼得·佩迪鲁化身的斑斑）就在旁边。在寻找魂器的旅途中，赫敏将窥镜作为安全警报使用。 |
