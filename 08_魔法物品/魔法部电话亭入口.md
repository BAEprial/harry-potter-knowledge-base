# 魔法部电话亭入口


| 项目 | 内容 |
|---|---|
| 名称 | 魔法部电话亭入口 |
| 英文名 | Ministry of Magic Visitor Entrance |
| 类别 | 魔法道具 |
| 说明 | 伦敦一个破旧的红色电话亭，是魔法部的来访者入口。拿起电话拨62442（拼写为MAGIC），会有一个女声询问来访目的，然后电话亭会像电梯一样沉入地下，将来访者送到魔法部大厅。在五年级哈利纪律审查会和七年级潜入魔法部盗取挂坠盒时都使用了这个入口。 |
