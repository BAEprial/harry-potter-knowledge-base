# 霍格沃茨特快列车


| 项目 | 内容 |
|---|---|
| 名称 | 霍格沃茨特快列车 |
| 英文名 | Hogwarts Express |
| 类别 | 传奇物品 |
| 说明 | 一列猩红色蒸汽火车，每年9月1日从伦敦国王十字车站九又四分之三站台出发，将学生们送往霍格沃茨。对每一个巫师来说，穿过九又四分之三站台的砖墙、第一次看到猩红色火车头的那一刻，是他们魔法人生的真正起点。车上有女巫推车售卖巧克力蛙、比比多味豆等零食。哈利与罗恩的友谊就始于霍格沃茨特快列车的车厢中。 |
