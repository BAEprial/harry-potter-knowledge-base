# 记忆球


| 项目 | 内容 |
|---|---|
| 名称 | 记忆球 |
| 英文名 | Remembrall |
| 类别 | 魔法道具 |
| 说明 | 一个水晶球大小的玻璃球，内含白烟。当持有者忘记了某件事时，球内的烟雾会变成红色。纳威的祖母在一年级送了他一个，烟雾立刻变红——但纳威完全想不起自己忘了什么（其实是忘了穿长袍）。马尔福抢走记忆球，哈利飞上空中追回，被麦格教授看到后反而成为了格兰芬多魁地奇队的找球手。 |
