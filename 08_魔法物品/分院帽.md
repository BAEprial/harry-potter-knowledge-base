# 分院帽


| 项目 | 内容 |
|---|---|
| 名称 | 分院帽 |
| 英文名 | Sorting Hat |
| 类别 | 传奇物品 |
| 说明 | 戈德里克·格兰芬多的旧帽子，被四位创始人施了魔法使其拥有智慧和判断力。每年开学时它会为新生分配学院——它能读取佩戴者内心深处的品质和愿望。帽子尊重佩戴者的意愿——哈利恳求"不要斯莱特林"时它选择了格兰芬多。在危急时刻，真正的格兰芬多人可以从帽中抽出格兰芬多之剑。每年开学宴上分院帽还会唱一首自创歌曲，有时还会发出关于学院团结的警告。 |
