# 复活石


| 项目 | 内容 |
|---|---|
| 名称 | 复活石 |
| 英文名 | Resurrection Stone |
| 类别 | 死亡圣器 |
| 说明 | 三件死亡圣器之一，能召唤已逝之人的灵魂影像（非真正复活）。它被镶在冈特戒指中，后被邓布利多取出。哈利在走向禁林面对伏地魔时转动复活石，见到了父母、小天狼星和卢平的灵魂陪伴他走完最后的路。 |
