# 魔法石（贤者之石）


| 项目 | 内容 |
|---|---|
| 名称 | 魔法石（贤者之石） |
| 英文名 | Philosopher's Stone |
| 类别 | 传奇物品 |
| 说明 | 尼可·勒梅创造的传奇魔法石，可以实现两个奇迹：将任何金属变成纯金，以及制造长生不老药。这是唯一已知的永生方法。伏地魔在第一学年试图偷取魔法石重塑身体，但哈利保护了它。在故事结束时，勒梅决定销毁魔法石，与妻子一同接受自然死亡。 |
| 是否已毁 | 被尼可·勒梅销毁 |
