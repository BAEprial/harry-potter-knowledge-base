# 预言球


| 项目 | 内容 |
|---|---|
| 名称 | 预言球 |
| 英文名 | Prophecy Orb |
| 类别 | 魔法道具 |
| 说明 | 魔法部神秘事务司预言厅中保存的水晶球，记录了有关哈利和伏地魔的完整预言。只有预言涉及的当事人才能安全地取下它。伏地魔为了得到完整预言而引诱哈利前往神秘事务司，导致了那场改变了一切的战斗。预言球在混战中被打碎。 |
| 是否已毁 | 在神秘事务司之战中被打碎 |
