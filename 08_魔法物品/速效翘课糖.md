# 速效翘课糖


| 项目 | 内容 |
|---|---|
| 名称 | 速效翘课糖 |
| 英文名 | Skiving Snackboxes |
| 类别 | 魔法道具 |
| 说明 | 弗雷德和乔治的得意之作——一系列双头糖果，吃一头会立刻出现症状（流鼻血、发烧、呕吐等），吃另一头症状立即消失。包括流鼻血牛轧糖、发烧软糖、呕吐奶油等。在乌姆里奇统治霍格沃茨期间，这些糖果成为学生们对抗暴政的秘密武器——几乎所有人都用它翘掉了乌姆里奇的课。韦斯莱魔法把戏坊的畅销产品。 |
