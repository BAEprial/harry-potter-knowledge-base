# 伏地魔的魔杖


| 项目 | 内容 |
|---|---|
| 名称 | 伏地魔的魔杖 |
| 英文名 | Voldemort's Wand |
| 类别 | 黑暗物品 |
| 说明 | 紫杉木杖身，13.5英寸，凤凰尾羽杖芯。与哈利的魔杖共享同一只凤凰（福克斯）的羽毛。这根魔杖施出了杀害詹姆和莉莉·波特的索命咒，也是伏地魔恐怖统治的象征。由于孪生杖芯的限制，伏地魔在墓地决斗中无法用它打败哈利，之后他不惜一切代价寻找老魔杖来解决这个问题。 |
