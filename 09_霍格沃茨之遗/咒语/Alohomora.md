## Casting Alohomora（英文原文）

As an essential spell, a screen prompt appears whenever Alohomora can be used on a locked door or chest. Pressing the specified key or button opens a minigame representing the lock's internal mechanism. The objective is to move two sparks into the correct positions in two concentric rings. When a spark is in the correct position, the corresponding set of gears starts to spin. When both sparks are correctly placed and held there for a few seconds, the lock will open. When using a keyboard, the Q-E keys control the green spark and the A-D keys control the red spark. When using a controller, the sparks are controlled by the left and right sticks. If the Difficulty is set to "Story", there is an "auto solve" option to skip the minigame.
