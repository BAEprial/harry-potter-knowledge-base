# 德姆斯特朗学院


| 项目 | 内容 |
|---|---|
| 名称 | 德姆斯特朗学院 |
| 英文名 | Durmstrang Institute |
| 位置 | 北欧（具体位置保密） |
| 类别 | 学校 |
| 说明 | 北欧著名魔法学校，以教授黑魔法（而非仅仅防御黑魔法）而闻名。学校的位置是严格保密的——学生被禁止告诉任何人学校在哪里。维克多·克鲁姆是德姆斯特朗最著名的学生，前校长卡卡洛夫曾是食死徒。格林德沃也曾在这里就读。 |
