# 小汉格顿墓地


| 项目 | 内容 |
|---|---|
| 名称 | 小汉格顿墓地 |
| 英文名 | Little Hangleton Graveyard |
| 位置 | 英格兰 |
| 类别 | 墓地 |
| 说明 | 里德尔家族的故乡和小汉格顿村附近的墓地。1995年，彼得·佩鲁姆将哈利和塞德里克·迪戈里传送至此，伏地魔在这里利用哈利的血液、父亲的骨灰和仆人的肉体重生。塞德里克在这里被虫尾巴杀害。墓地中还埋葬着伏地魔的父亲汤姆·里德尔及其祖父母——伏地魔曾在这里杀害了自己的父系家族。 |
