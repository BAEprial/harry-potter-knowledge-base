# 魔法部法庭


| 项目 | 内容 |
|---|---|
| 名称 | 魔法部法庭 |
| 英文名 | Ministry Courtrooms |
| 位置 | 魔法部地下 |
| 类别 | 政府机构 |
| 说明 | 魔法部的审判法庭，位于地下深处。最大的法庭（第十审判庭）曾是审讯食死徒的场所，有数十把用铁链锁住的椅子环绕中央被告席。哈利在这里接受了使用未成年魔法的听证会，邓布利多为他辩护。这个法庭象征着魔法法律体系的威严与冷酷。 |
