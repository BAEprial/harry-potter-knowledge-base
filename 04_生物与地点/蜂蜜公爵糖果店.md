# 蜂蜜公爵糖果店


| 项目 | 内容 |
|---|---|
| 名称 | 蜂蜜公爵糖果店 |
| 英文名 | Honeydukes |
| 位置 | 霍格莫德 |
| 类别 | 商业场所 |
| 说明 | 霍格莫德最受学生欢迎的商店，出售各种魔法糖果：比比多味豆（包括鼻屎味和呕吐味）、巧克力蛙（附赠著名巫师卡片）、嘶嘶蜥蜴糖、吹宝超级泡泡糖、冰鼠等。地窖有一条秘密通道直通霍格沃茨（哈利通过活点地图发现了它），成为他在没有霍格莫德许可证时偷溜出城堡的捷径。 |
