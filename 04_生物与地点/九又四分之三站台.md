# 九又四分之三站台


| 项目 | 内容 |
|---|---|
| 名称 | 九又四分之三站台 |
| 英文名 | Platform 9¾ |
| 位置 | 伦敦国王十字车站 |
| 类别 | 交通枢纽 |
| 说明 | 隐藏在9号和10号站台之间的魔法站台，是霍格沃茨特快列车的始发站。巫师需要直接穿过两站台之间的隔墙才能到达（最好跑着穿过去）。红色的霍格沃茨特快列车每年9月1日上午11点准时发车。多比曾封锁了入口阻止哈利和罗恩。 |
