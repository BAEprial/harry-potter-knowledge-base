| 项目 | 内容 |

| 名称 | 霍格莫德村 |
| 英文名 | Hogsmeade |
| 位置 | 苏格兰 |

| 说明 | 英国唯一一个纯巫师居住的村庄，三年级以上学生在周末可以凭许可证前往。著名地点包括三把扫帚酒吧（罗斯默塔夫人经营）、猪头酒吧（邓布利多的弟弟阿不福思经营）、蜂蜜公爵糖果店、佐科恶作剧商店和尖叫棚屋。 |
