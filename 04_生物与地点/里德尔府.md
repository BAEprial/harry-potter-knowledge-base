# 里德尔府


| 项目 | 内容 |
|---|---|
| 名称 | 里德尔府 |
| 英文名 | Riddle House |
| 位置 | 小汉格顿 |
| 类别 | 住宅 |
| 说明 | 里德尔家族的豪宅，伏地魔的父亲汤姆·里德尔一家曾居住于此。1943年，年轻的伏地魔在这里杀害了自己的父亲和祖父母，嫁祸给舅舅莫芬·冈特。在伏地魔重生后的第二年，他在此处审讯并杀害了伯莎·乔金斯，也在此处策划了三强争霸赛的阴谋。这座房子最终被废弃，成为当地传说的来源。 |
