# 禁林


| 项目 | 内容 |
|---|---|
| 名称 | 禁林 |
| 英文名 | Forbidden Forest |
| 位置 | 霍格沃茨校园 |
| 类别 | 森林 |
| 说明 | 霍格沃茨校园边的广袤危险森林，栖息着独角兽、半人马（弗伦泽和群落）、八眼蜘蛛（阿拉戈克的后代）、夜骐等神奇生物。学生被严禁进入，但哈利几乎每年都会踏足。这里也是哈利最后走向"赴死"的地方。 |
