# 速速变大

> 英文名：Engorgio

## 中文百科（Leo555 整理）

| 项目 | 内容 |
|---|---|
| 中文名 | 速速变大 |
| 英文名 | Engorgio |
| 类型 | 咒语 |
| 分类 | 实用 |
| 效果 | 使目标物体增大 |
| 首次出现 | 《哈利·波特与火焰杯》 |
| 说明 | 膨胀咒，可以使物体增大到数倍大小。对应的缩小咒是"速速缩小"（Reducio）。穆迪教授在课堂上曾用此咒将蜘蛛放大以便学生观察不可饶恕咒的效果。海格也被怀疑偷偷使用过这个咒语来种植超大南瓜。 |
