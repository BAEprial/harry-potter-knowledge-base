# 无声无息

> 英文名：Silencio

## 中文百科（Leo555 整理）

| 项目 | 内容 |
|---|---|
| 中文名 | 无声无息 |
| 英文名 | Silencio |
| 类型 | 咒语 |
| 分类 | 实用 |
| 效果 | 使目标发不出声音 |
| 首次出现 | 《哈利·波特与凤凰社》 |
| 说明 | 消音咒，可以让对象完全无法发出声音。五年级魔咒课上弗立维教授教授此咒。赫敏第一次尝试就成功让一只乌鸦噤声，而罗恩的乌鸦越叫越大声。在战斗中也可以用来阻止敌人念咒（如果对方不会非语言咒语的话）。 |
