# 声音洪亮

> 英文名：Sonorus

## 中文百科（Leo555 整理）

| 项目 | 内容 |
|---|---|
| 中文名 | 声音洪亮 |
| 英文名 | Sonorus |
| 类型 | 咒语 |
| 分类 | 实用 |
| 效果 | 放大施咒者的声音 |
| 首次出现 | 《哈利·波特与火焰杯》 |
| 说明 | 扩音咒，使施咒者的声音被魔法放大，如同使用了扩音器。卢多·巴格曼在魁地奇世界杯上用它解说比赛，伏地魔在霍格沃茨大战中用它向全校喊话。对应的消音咒是"悄声细语"（Quietus）。 |
