# 乌龙出洞

> 英文名：Serpensortia

## 中文百科（Leo555 整理）

| 项目 | 内容 |
|---|---|
| 中文名 | 乌龙出洞 |
| 英文名 | Serpensortia |
| 类型 | 咒语 |
| 分类 | 黑魔法 |
| 效果 | 从魔杖尖端召唤出一条蛇 |
| 首次出现 | 《哈利·波特与密室》 |
| 说明 | 蛇召唤咒，马尔福在与哈利的决斗俱乐部对战中使用了这个咒语，召唤出一条黑蛇。蛇是一种危险的魔法生物，只有蛇佬腔才能控制它。斯内普随即用蛇消失咒驱散了蛇。 |
