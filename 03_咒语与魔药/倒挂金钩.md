# 倒挂金钩

> 英文名：Levicorpus

| 效果 | 将目标倒挂在空中 |
| 首次出现 | 《哈利·波特与混血王子》 |
| 说明 | 由年轻时代的斯内普（"混血王子"）发明的非语言咒语。在学校期间曾非常流行。詹姆·波特曾用这个咒语将斯内普倒挂羞辱——这成为了"斯内普最糟糕的记忆"。反咒为"金钟落地"（Liberacorpus）。 |
