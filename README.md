# 哈利波特系列知识库 / Harry Potter Knowledge Base

一个用 Obsidian 搭建的哈利波特系列双语知识库。以中文整理为主，保留英文原名；笔记之间用双向链接相连，可用 Dataview 自动汇总成表格。

An Obsidian vault for the Harry Potter series, in Chinese with original English names retained. Notes are connected with wikilinks, and Dataview is used to generate automatic tables.

## 使用方式 / How to use

1. 下载本仓库，或用 Obsidian 的 "Open folder as vault" 打开该文件夹。
   Download this repository, or open the folder in Obsidian via "Open folder as vault".
2. 安装两个社区插件：**Dataview** 和 **Templates / Templater**（本库的总览页用到 Dataview 查询）。
   Install two community plugins: **Dataview** and **Templates / Templater** (overview pages use Dataview queries).
3. 打开 `00_首页/首页.md` 作为入口。首页的表格由 Dataview 自动生成。
   Open `00_首页/首页.md` as the entry point; its tables are generated by Dataview.
4. 用全局搜索（`Ctrl+Shift+F`）按中文名或英文名查找条目。
   Use global search (`Ctrl+Shift+F`) to find an entry by its Chinese or English name.

本仓库不包含插件安装包（第三方代码，有版权）。请从 Obsidian 的插件市场自行安装；插件启用清单见 `.obsidian/community-plugins.json`。
Plugin binaries are not included (third-party code). Install them from Obsidian's community plugin browser; see `.obsidian/community-plugins.json` for the enabled list.

## 命名与翻译约定 / Naming and translation conventions

- 有通行中文译名的条目用中文名做文件名，英文原名保留在 YAML 的 `英文名` 字段与正文开头。
  Entries with an established Chinese name use it as the filename; the English name is kept in the `英文名` YAML field and at the top of the note.
- 没有通行译名的条目（大量配角、路人）保留英文原名，未编造中文译名。
  Entries without an established Chinese translation (many minor characters) keep their English names; no Chinese names were invented.
- 咒语原文（如 `Expecto Patronum`）不翻译，保留拉丁文形式。
  Incantations (e.g. `Expecto Patronum`) are kept in their original form.
- 字段值（学院、血统等）的常见项做了英译中，其余保留英文原文。
  Common field values (house, blood status, etc.) are translated; the rest remain in English.
- 部分卡片带有「中文百科（Leo555 整理）」段，为中文原创的传记、台词、花絮等；不同译名的条目另建独立卡，互为补充。
  Some notes include a "中文百科（Leo555 整理）" section with original Chinese biographies, quotes and trivia; entries under alternative translations are separate, complementary notes.
